Для работы напечатанного QR-кода необходимо сохранять аккаунт
`mesedusajpudinova001-tech`, репозиторий `mesedu.portfolio`,
включённую публикацию GitHub Pages и старые пути `zadu/`.
После подключения собственного домена этот адрес также нужно сохранить.

## Публикация и обновление меню

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Дальнейшие изменения меню вносить в этот репозиторий `zadu-menu`.
Основные данные: `interior/menu/menu-data.json`.
Генерация страниц: `python scripts/render-menu.py`.
Главная страница: `interior/index.html`.
Фотографии блюд: `assets/dishes/`.
WhatsApp: `https://wa.me/79282249222`.

## Подключение купленного домена

1. Выбрать свободное имя у регистратора и зарегистрировать его на данные
   согласованного владельца. При покупке проверить стоимость продления.
2. В настройках профиля GitHub открыть Settings → Pages → Add a domain,
   указать купленное имя. Добавить выданную GitHub запись TXT в DNS
   регистратора, затем нажать Verify. Сохранить эту TXT-запись.
3. В этом репозитории `zadu-menu` открыть Settings → Pages →
   Custom domain, указать домен без https:// и путей, затем Save.
4. В DNS регистратора для корня домена добавить четыре отдельные записи A:

   | Тип | Имя | Значение |
   | --- | --- | --- |
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | mesedusajpudinova001-tech.github.io |

   Существующие записи парковочной страницы для @ и www заменить
   соответствующими записями из таблицы. Другие записи, например почты,
   сохранять. Значение CNAME не содержит имени репозитория.
5. Дождаться обновления DNS и выпуска HTTPS-сертификата, затем включить
   Enforce HTTPS. Обновление DNS и доступность HTTPS могут потребовать
   до 24 часов.
6. Проверить свой домен, открытие разделов и блюд, фотографии и старый
   QR-адрес. GitHub Pages перенаправляет прежний адрес отдельного сайта
   на подключённый домен; при необходимости старые переходы также можно
   обновить после проверки домена.

Домен кофейни подключать к `zadu-menu`. В `mesedu.portfolio`
не добавлять домен кофейни или его CNAME. Отдельный платный хостинг
для текущего размещения не нужен.
